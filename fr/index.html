Comment un verdict est rendu

Le modèle lit. Le code applique les règles.

  • Les critères, mot pour mot

    Copié de l’appel d’offres, vérifié sur sa page.

  • Une recherche par élément

    Chaque élément est cherché à part.

  • Démontré, ou une lacune

    Une exigence compte si le CV l’énonce ou si le travail la prouve.

  • Chaque phrase vérifiée

    bearout vérifie chaque phrase; un échec est réécrit une fois ou retiré.
