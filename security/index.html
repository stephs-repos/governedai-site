Security

Where data is kept

  • Client data

    Stored on Microsoft Azure in Canada Central (Toronto). Copies of the database backups and of stored files are kept in Canada East (Quebec City), so the service can be restored if Canada Central is unavailable.

  • Staff sign-in

    The sign-in identities of our own staff (names, work emails and multi-factor authentication registrations) are held by Microsoft Entra ID in Microsoft’s North America data location, which may be in the United States. A tenant’s data location is fixed when it is created. No CV or consultant record is held there. If a client’s own users sign in to CVCite, their sign-in identities are held there in the same way.

Sub-processors

  • Microsoft Azure

    Hosting, database, file storage, keys and backups, in Canada. Staff sign-in through Microsoft Entra ID, as above.

  • Anthropic

    The AI model provider, used only for CVCite’s AI features: a free match and the hosted beta that builds the grid. Requests are processed in the United States. We have applied for zero data retention; it has not been granted. No client data from a discovery engagement is sent to it.

  • Zoho Mail

    Email to info@governedai.ca, including any files sent with it, in Zoho’s Canadian data centre.

How it is protected

  • Private networking

    The service runs as jobs with no public endpoint, and the database is reachable only on a private network.

  • Encryption

    All data is encrypted at rest, and in transit with TLS, including connections to the database.

  • Access

    Multi-factor authentication is required on every staff account. Access to the environment is granted through Microsoft Entra roles.

  • Backups

    Backups allow a restore to any point in the last 35 days. We test a restore at least every three months, starting before the first client data is stored.

  • Deletion

    Deleted data leaves the backups, and their copies in Canada East, within 35 days.

  • Reporting a security problem

    Write to info@governedai.ca with “Security report” in the subject. Please give us a chance to fix the problem before you make it public.
