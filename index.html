How a verdict is reached

The model reads. Code applies the rules.

  • The criteria, word for word

    Each criterion is copied from the RFP and checked against its page.

  • A search for every part

    A criterion that lists several things gets a search for each.

  • Shown, or a gap

    A requirement counts only when a CV passage states it or the work it describes proves it.

  • Every sentence checked

    bearout tests each sentence against its passage; a failure is rewritten once or removed.
