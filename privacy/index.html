Privacy

  • This site

    No cookies, no analytics and no forms. The host and Google Fonts receive your IP address when the page loads, as any web server does.

    Mail to info@governedai.ca is handled by Zoho Mail. It is read by Steph and used only to reply.

  • A free match

    The RFP and CV you send are processed through Anthropic’s API, in the United States. Send them with names, phone numbers and clearance details removed.

    Both files are deleted within a set number of days of delivery. Ask at any time for them to be deleted sooner.
